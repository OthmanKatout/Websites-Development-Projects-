# 🧮 Calculator

A simple and functional **calculator web application** built using **HTML, CSS, and JavaScript**.

This project is one of my first steps into JavaScript and was created to practice turning a static webpage into an interactive application.

## 🛠️ Technologies Used

* **HTML5** — Structure of the calculator.
* **CSS3** — Styling, layout, and visual design.
* **JavaScript** — Calculator logic, calculations, and user interaction.

## 🎯 Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🔢 Support for numerical input
* 🧹 Clear/reset functionality
* ⚡ Instant calculation through JavaScript
* 🖥️ Simple and clean user interface

## 📚 What I Learned

While building this project, I practiced:

* Connecting JavaScript with HTML.
* Working with the **DOM**.
* Handling button clicks and user input.
* Using JavaScript functions.
* Performing mathematical operations.
* Updating webpage content dynamically.
* Using CSS to create a clean calculator layout.
* Understanding how HTML, CSS, and JavaScript work together.
