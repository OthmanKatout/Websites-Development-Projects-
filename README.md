# 🌐 My Personal Story

A personal website that tells my journey from **high school to university**, sharing some of the experiences, interests, and milestones that have shaped me along the way.

This is one of my first web development projects, created as a way to practice what I learned while building something personal and meaningful.

## 🛠️ Technologies Used

* **HTML5** — Used to structure the website and organize the content.
* **CSS3** — Used to design the layout, colors, fonts, spacing, and overall appearance.

No JavaScript or frameworks were used in this project.

## 🎯 Purpose of the Project

I built this website to:

* Practice the fundamentals of **HTML and CSS**.
* Learn how to structure a complete webpage.
* Experiment with CSS styling and layouts.
* Create my first personal website.
* Turn my own story into a real web project.

## 📖 About the Website

The website presents different stages of my journey, starting from high school and continuing into my university life.

It reflects some of the experiences and changes I went through and how they influenced my interests and development as a student.

## 📚 What I Learned

While building this project, I practiced:

* HTML page structure
* Headings, paragraphs, images, and links
* CSS selectors
* Colors and typography
* Margins and padding
* Flexbox
* Positioning and layouts
* Responsive design basics
* Connecting HTML with external CSS
