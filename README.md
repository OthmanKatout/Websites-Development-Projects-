# 📝 Interactive To-Do List Application

A dynamic, light-weight web application that helps users organize daily tasks into active and completed categories. Built with modern vanilla JavaScript, HTML5, and CSS3.

---

## 🌟 Key Features

* **Dynamic Task Creation:** Add new tasks with customized names (up to 27 characters).
* **Two-Stage Task Lifecycle:**
  * **Active Tasks List:** Default list for ongoing items.
  * **Completed Tasks List:** Check off an item to automatically move it to the completed section.
* **Bi-directional Toggling:** Unchecking a task moves it back to the active list instantly.
* **Bulk Clearing:** Single-click "Clear All" functionality dedicated to each task list.
* **Responsive Interactive UI:** Dynamic modal popup for streamlined task entry.

---

## 🛠️ Built With

* **HTML5:** Semantic layout structure and custom inputs.
* **CSS3:** Responsive styling and component layouts.
* **JavaScript (ES6+):** Pure DOM manipulation, array management, and event-driven architecture.
